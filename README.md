# QD58-2026-memoir 🎵✨

> "The soundtrack of the halcyon days of our high school."
> 
> 属于我们的高中回忆录，也是通往青春时光的专属启动页。

## 📖 项目简介 (About)

`QD58-2026-memoir` 是一个充满仪式感的 **Startup Page（启动页）**。它作为一扇大门，将承载着我们无数回忆的专属班级论坛连接起来。

这里不仅是一个静态的网页，更是一个“时间胶囊”。我们通过精心挑选的音乐、定制设计的字体与排版，希望每一位老同学在打开的瞬间，就能被拉回那段名为“QD58”的美好时光。点击进入，即可跳转至我们自主开发的高中班级回忆论坛，重温那些闪闪发亮的日子。

**在线预览**：[qd58.eon21.space](https://qd58.eon21.space)

## ✨ 核心特性 (Features)

- 🚪 **专属启动页体验**：作为班级论坛的“前奏”，极简且富有情感的界面设计，营造出强烈的归属感和登录仪式感。
- 🔗 **一键直达班级论坛**：核心功能，点击交互即可无缝跳转至我们自主开发的高中班级回忆论坛。
- 📻 **青春原声带**：内置 `music` 文件夹，加载页面时自动播放属于我们的专属背景音乐，氛围感拉满。
- 🎨 **定制排版与视觉**：引入了定制的 `fonts` 字体，并对页面排版（letter area）与字体像素（font px）进行了多次精心打磨，确保最佳阅读体验。
- 📱 **多终端与微信适配**：包含微信内部访问的验证文件，确保了在微信群内分享时，同学们可以直接顺畅地打开这份“回忆邀请函”。
- 📄 **多页面支持**：包含主启动页（`index.html`）、关于页（`about.html`）以及历史迭代版本。

## 🚀 本地运行 (Getting Started)

克隆仓库到本地：
```bash
git clone https://github.com/FrancisAMD/QD58-2026-memoir.git
```
进入项目目录：
```bash
cd QD58-2026-memoir
```
直接双击打开 index.html，或者使用本地服务器（如 VS Code 的 Live Server）预览。
