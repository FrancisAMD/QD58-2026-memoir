【背景音乐使用说明】

1. 把音乐文件放进本文件夹（music/），推荐 mp3 格式。
   例如：01.mp3、02.mp3、夏日.mp3

2. 打开项目根目录的 script.js，找到顶部这一段：

   const MUSIC_TRACKS = ['01', '02', '03'];

   把文件名（不要后缀）写进去，例如：
   const MUSIC_TRACKS = ['01', '02', '夏日'];

3. 页面右上角点 ♪ 会弹出菜单：
   - 上面是歌曲列表（显示不带后缀的文件名）
   - 点某一首即切换并播放（同时取消静音）
   - 最下面是「静音 / 取消静音」

4. 默认进入页面是静音状态；选择歌曲或点「取消静音」后才会出声。

注意：文件名尽量避免空格；中文文件名一般可以，若个别浏览器有问题可改用英文/数字。
