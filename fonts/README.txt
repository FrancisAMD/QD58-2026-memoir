霞鹜文楷本地字体说明
====================

网页样式已经配置为优先加载：
  fonts/LXGWWenKaiLite-Regular.ttf

将官方“霞鹜文楷轻便版”字体文件复制到本目录，并命名为：
  LXGWWenKaiLite-Regular.ttf

官方项目（字体下载与授权说明）：
https://github.com/lxgw/LxgwWenKai-Lite

该字体采用 SIL Open Font License 1.1。若随项目再分发字体文件，
请同时保留官方仓库中的 OFL.txt 授权全文。

说明：当前执行环境无法直接取得 GitHub 的二进制字体文件，因此本压缩包先包含本地字体加载配置和放置说明；在字体文件放入此目录前，网页会回退到原有在线字体服务。放入字体后，本地字体优先生效。
